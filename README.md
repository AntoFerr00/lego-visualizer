# 🧱 Lego Visualizer

A 3D Lego builder in the browser. Click to place bricks, drag to orbit.

![Demo](https://img.shields.io/badge/demo-live-brightgreen)

## Features

- ✅ **Realistic Lego geometry** — studs, tubes, exact proportions
- ✅ **10 official colors** — red, blue, yellow, green, black, white, gray, orange, purple, brown
- ✅ **7 piece types** — 1×1, 1×2, 1×4, 2×2, 2×3, 2×4, 4×4
- ✅ **Grid snapping** — pieces align perfectly
- ✅ **3D orbit controls** — rotate, pan, zoom
- ✅ **Semi-transparent preview** — see where pieces will land

## Quick Start

```bash
npm install
npm run dev
```

Open http://localhost:5173

## Controls

| Action | Input |
|--------|-------|
| Place brick | Left click on grid |
| Rotate camera | Right click drag |
| Pan camera | Middle click drag |
| Zoom | Scroll wheel |
| Clear all | Click 🗑️ button |
| Auto-rotate | Click 🔄 button |

## Tech Stack

- **Three.js** — 3D rendering
- **Vite** — Fast dev server & build
- **HTML/CSS/JS** — No framework bloat
